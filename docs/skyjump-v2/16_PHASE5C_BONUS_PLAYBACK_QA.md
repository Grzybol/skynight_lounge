# SKYJUMP V2 — Phase 5C Bonus Playback QA

**Status:** DEV preview can play 24 deterministic Free Spin books on `feat/skyjump-v2-5x5`.  
**Not in this phase:** math retune, Rejump, Wind Key, Flight Multiplier, `SPECIAL_WORLD_RECORD`, production books, production LUT.

Books are generated by `math/games/0_0_poc/skyjump_v2_phase5c_samples.py` and stored in `skyjump_v2_bonus_samples.json`. The frontend replays those events through the existing player, reducers, and handlers. It does not draw outcomes.

`resolve_v2_round` accepts optional `base_stops`, `next_fs_stops`, and `round_prior_win_x`. Omitted arguments keep the Phase 5B path. Phase 5B tests still pass. Sample 18 sets a synthetic prior of `49999.9` so a normal Large Hill line crosses the 50,000x cap. That prior is DEV-only and is marked `devSyntheticCapPrior` on the base result.

## Resume

Resume samples keep the full event list. `resumeBookEvents` builds `createBonusSnapshot` from the reserved prefix and leaves the tail to the normal player. `convertTorResumableBet` uses that helper. DEV preview sets `active: true` and `event: '0'` on the reconstructed list so `newGame` plays the snapshot and then the tail.

Python tests reduce the full book and the reserved-prefix-plus-tail book and compare bonus tier, spins, token floor, persistent targets, gate flag, cap flag, and capped win. Samples 19–24 match.

Playback bug found: `createBonusSnapshot` left `resumeCatchUp` true, so the tail skipped reel waits and finished in one flash. The handler now clears the flag before the tail. Sample 20 was rechecked and the remaining spins play one by one.

## Bugs found and fixes

| Bug | Fix |
| --- | --- |
| `checkIsBonusGame` ignored `skyjumpFreeSpinsStart` nested inside `createBonusSnapshot`, so a reconstructed resume book was not a bonus game | Search snapshot `bookEvents` as well. `active` still forces true |
| Persistent Mystery transforms were recorded on the HUD but the cells stayed regular symbols | `skyjumpV2PersistentApply` sets those cells to Mystery and shows `PERSISTENT TARGET` |
| Resume catch-up never cleared, so the tail did not animate | Clear `resumeCatchUp` at the end of the snapshot handler |
| In-flow bonus banner pushed the grid through the HUD | Banner and win pill overlay the board. Grid stays in the play area |
| Cap card did not show `terminated` | Win label `MAX WIN · TERMINATED` and `terminated true/false` |

No BASE or Free Spin weights, Coach rates, Scatter rates, Mystery weights, bonus EV, or tier rules were changed.

## Production bundle

Bonus JSON is imported only by `bonusSamples.ts`, which is imported by `localDemo.ts`. `localDemo.ts` is loaded with `import()` inside `import.meta.env.DEV` in `actor.ts` and on `/dev-preview`. The source selector is a dynamic import from the board, also behind `import.meta.env.DEV`.

After `npm run build`, the production `build/` output has no `BONUS SAMPLE`, `phase5c-bonus`, `skyjump-v2-dev-source`, `3 Scatter to Large Hill`, `devSyntheticCapPrior`, or `nonProduction`. The real Free Spin HUD copy, including `Persistent Mystery Targets`, remains in the client bundle.
